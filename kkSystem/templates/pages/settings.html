How to use the SK Profiling Management System

This operational playbook helps you manage individual member registries, generate systemic reports, and organize youth workflows.

Getting Started
  1. Log in securely using your authorized administrator credentials.
  2. You will land on the primary insights dashboard showing aggregate youth metrics.
  3. Navigate across application models seamlessly via the collapsing sidebar channels.
  4. Always terminate your current sequence via the secure Logout anchor in the profile hub when complete.
Dashboard

The analytics matrix compiles demographic vectors automatically across your barangay footprint:

  • Audit active total census tallies isolated by employment or academic profiles.
  • Visualize dynamic age distribution plots mapping community cohorts.
  • Review gender ratios alongside automated data summary readouts.
  • Export structured tabular snapshots natively to file sheets for council reference.
Youth Records Management

Centralized database toolset to create, edit, modify, and track resident entity schemas:

Adding a New Profile:
  1. Click the add record trigger to instantiate a blank workspace form.
  2. Fill input inputs, noting fields marked with explicit asterisks are mandatory.
  3. Select the active status flag (Student, Working, or Out of School).
  4. Append conditional fields (e.g., specific occupation data for working classification).
  5. Commit the save execution to write parameters permanently to the dataset.
